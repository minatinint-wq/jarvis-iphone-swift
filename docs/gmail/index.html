JARVIS XLV — Conector Gmail

Integração pessoal de e-mail para o assistente JARVIS XLV. O programa consulta a API oficial do Gmail para apresentar remetente, assunto e data no visor local e anunciar novos e-mails pelo áudio configurado pelo usuário.

O acesso é autorizado pelo Google com OAuth e é limitado a metadados. O conector não envia, exclui ou marca mensagens como lidas e não depende de uma aba de Gmail aberta.

Este site apresenta a integração; não recebe mensagens, credenciais ou tokens de e-mail. A configuração é feita no aplicativo local do usuário.

Política de privacidade

Suporte: use o e-mail de suporte identificado na tela de consentimento Google ou a seção Issues do projeto JARVIS, sem publicar dados pessoais ou credenciais.
